O navegador não permite abrir sozinho a pasta onde este arquivo está; por isso a escolha é feita aqui, no início. A pasta fica lembrada nas próximas vezes.

Meus modelos de despacho

Um modelo para cada resultado. Quando o modelo do resultado estiver vazio, o despacho sai no formato automático. Os modelos ficam guardados só neste navegador; use “Baixar modelos” para ter uma cópia ou levá-los para outro computador.

Como escrever o modelo e campos disponíveis (clique num campo para inseri-lo)
Cada linha vira um parágrafo. Linha começando com # vira título (ex.: # DA CONCLUSÃO); com - vira item com marcador; com | fica centralizada. Use **texto** para negrito e {{n}} para a numeração automática dos parágrafos (ex.: {{n}}. Ante o exposto…).
Uma lista ou um bloco sozinho na linha é inserido completo (em itens ou com os parágrafos do texto automático); no meio de uma frase, entra como texto corrido. Campos não preenchidos no processo saem como [PREENCHER].
